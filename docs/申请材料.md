### 4. 项目描述（核心字段）
```
项目名：小浩智能助手 (XiaoHao Assistant)

这是一个个人开发的通用AI助手平台，支持接入多种国产大模型API，
提供智能问答、文档总结、知识图谱构建等功能。

起因是我在做日常学习和工作时经常需要查阅大量文献和报告，
手动整理效率很低，所以做了这个工具来辅助自己。
后来发现身边同学也有类似需求，就想把它做得更完善一些。

目前已完成的功能：
- 多轮智能问答：支持上下文理解的连续对话
- 文档自动总结：针对学术论文、研究报告做结构化摘要
- 知识图谱提取：从文本中提取概念关系，辅助知识梳理
- 批量问答：基于同一份文档一次回答多个问题

技术栈：
后端 Node.js + Express，前端原生 HTML/CSS/JS，
通过 OpenAI 兼容格式统一对接各家模型的 API 接口，
目前支持智谱GLM、通义千问、DeepSeek、Kimi 等5个平台的模型切换。

为什么想用 MiMo：
之前一直关注小米的大模型进展，MiMo 开源后试用了下，
感觉在中文理解和代码能力方面都不错，性价比也高。
如果能拿到激励计划的 Token 配额，我计划把 MiMo 作为默认模型之一接入进来，
让更多用户也能体验到国产大模型的能力。
同时也想基于 MiMo 做一些中文场景的专项优化测试，
比如学术论文阅读、中文长文处理这些场景下的效果对比。
```
